# SMS Landing Page

Portfolio landing page for the Supermarket Management System project.

## Setup

1. Replace all `YOUR_DEPLOYED_URL` with your actual deployed URL
2. Update the demo credentials if needed
3. Push to GitHub → import to Vercel → deploy

## Deploy to Vercel

1. Push this folder to a new GitHub repo
2. Go to vercel.com → New Project → Import the repo
3. No configuration needed — Vercel detects static HTML automatically
4. Done — your landing page is live
